# 通用对话平台使用教程

适用于 DeepSeek、Kimi、豆包、腾讯元宝、通义千问及其他普通 AI 对话产品。

这些产品未必支持 Codex 的 `SKILL.md` 安装机制，因此采用“核心提示词 + 知识文件 + 用户数据”的方式。

## 推荐方法

1. 新建一个独立对话，避免旧对话干扰；
2. 复制 `core/SYSTEM-PROMPT.md` 中的完整核心提示词，作为第一条消息；
3. 上传 `dist/hongyu-xhs-live-diagnosis-all-in-one.md`，或分别上传 `references/` 中的文件；
4. 再上传千帆截图、表格和必要背景；
5. 发送诊断请求。

示例请求：

```text
请按照刚才的红域小红书直播复盘规则，诊断我上传的这场直播。

类目：
价格带：
主播：
是否投流：
本场目标：

请先判断资料完整度，再定位最重要的三个问题，并给出下一场可验证方案。
```

## 如果平台支持“自定义助手/项目/系统指令”

- 把 `core/SYSTEM-PROMPT.md` 放入系统指令；
- 把知识文件放入该助手或项目的长期知识库；
- 每次只需上传本场截图和背景数据。

## 如果平台只支持普通聊天

每次新开对话都重新粘贴核心提示词。若上下文有限，优先提供：

1. 核心提示词；
2. `diagnosis-framework.md`；
3. 当前任务需要的专项文件；
4. 本场数据。

## 图片识别失败时

不同平台的多图、长截图、表格和小字号识别能力差异很大。出现数字漏读、单位误读或无法识别时：

- 改用平台导出表格；
- 分段上传清晰截图；
- 使用OCR后把文字与原截图一起提交；
- 要求AI先列出它识别到的指标，让用户核对后再诊断。

不要让AI根据模糊图片猜数字。

## 重要限制

通用版只能统一方法，不能统一各平台的实际表现。应至少使用一组相同资料，分别测试：

- 指标提取准确率；
- 是否区分事实与假设；
- 是否武断认定限流；
- 是否输出可执行方案；
- 是否遗漏观看人数、支付金额和新增粉丝曲线。
