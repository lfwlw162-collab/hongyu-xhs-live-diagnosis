# 直播诊断框架

本框架来自红域工场直播实操、陪跑与复盘方法。阈值是经验参考，不是小红书官方统一标准。

## 证据层级

输出时使用以下标签：

- **数据事实**：截图、表格或回放直接显示。
- **高可信诊断**：多个数据相互支持，且能排除主要替代解释。
- **待验证假设**：合理但缺少回放、商品、投流或历史对照。
- **缺失证据**：目前无法判断，说明应补什么。

## 先核对口径

- 区分曝光人数、封面曝光次数、观看人数、观看次数。
- 区分商品曝光人数、商品点击人数、加购人数/次数、支付人数/订单数。
- 平台展示的“观看-成交率”优先按平台口径引用；自行计算时写清分子分母。
- GPM = 成交金额 / 观播人数 x 1000。
- 同期退款金额 / 同期成交金额只能称为退款成交简单比值；严格退款率需把退款匹配回原订单或场次。

## 漏斗诊断顺序

### 1. 曝光 -> 进房

看直播间曝光、封面曝光、观看人数、封面点击率及来源结构。

经验参考：

- 日常普通场每小时约 1000-1500 次曝光可作为保底感知；长期低于 1000 需排查账号、规则、选品、标题封面或类目环境。
- CTR 约 3.5%-4%为合格感知，超过 4%较好；大场覆盖更广时约 3%不必直接判差。
- 普通日常场每小时约 80-120 观播可作参考，但必须结合类目与账号历史。

曝光低且 CTR、进房后数据不差：排查分发、账号/商品风险、开播稳定性和外部环境。

曝光足但 CTR 低：优先排查封面、标题、定位、价格带信号和封面承诺。

CTR 高但进房后停留低：封面承诺与首屏内容可能不一致。

### 2. 进房 -> 停留/互动

看人均观看、30/60 秒留存、上下滑平均停留、互动率、关注率和实时在线趋势。

经验参考：

- 带货间人均观看约 90 秒以上可视为健康感知；冷启动期约 45 秒可接受。
- 长期低于 60 秒，优先检查场景、首屏品和首屏话术。
- 30 秒留存目标约 40%-50%以上，60 秒留存目标约 25%以上。
- 上下滑渠道平均停留低于 8 秒，优先排查第一眼画面、前三秒话术和首屏商品。
- 互动率约 5%可作及格感知；起号阶段关注率约 3%可作观察目标。

主页/关注停留好而上下滑差：内容能服务熟人，但对陌生人缺少快速理解和钩子。

### 3. 商品曝光 -> 点击

看商品曝光人数、点击人数、曝光-点击率、讲解时间与具体 SKU。

点击低可能来自：商品不适合当前人群、视觉展示弱、链接/SKU复杂、讲解没有点出人群与场景。

点击高只能证明兴趣，不代表购买意愿已经形成。

### 4. 点击/加购 -> 支付

看点击-支付率、观看-支付率、加购人数/次数、支付人数/订单、价格带和渠道。

经验参考：

- 加购率低于约 13%需要警觉，但不同类目差异很大。
- 加购已不低而支付转化低于约 20%，优先排查价格、优惠复杂度、售后、真伪、适配和即时购买理由。
- 手册中的“支付转化率 = 成交人数 / 加购人数”是便于复盘的非标准口径，目标区间约 30%-60%仅作经验参考。

高点击低支付常见原因：用户怕买错、规格/尺码/成色不清、价格价值未讲透、售后不清、商品页信息不足、货不对人。

### 5. 支付 -> 退款/利润

看退款的 SKU、原因、成交场次、主播、时段、渠道和是否发货。

古着/服饰重点排查：实测尺码、主播身高体重、松紧、成色等级、瑕疵近景、色差和退换规则。

美妆等类目重点排查：适用人群、功效边界、成分/过敏提示、规格误解和过度承诺。

GMV增长但退款、折扣、投流或履约成本同步上升时，不得称为经营改善。

## 流量渠道

至少比较各渠道的观看人数、人均观看、成交额、订单、客单价和观看-成交率。

- 公域量大但成交弱：检查封面承诺、首屏承接、笔记与货盘匹配、陌生人信任。
- 群聊/消息量小但成交强：说明私域信任有效，但不能用私域 GMV 掩盖公域承接问题。
- 笔记进房多但成交弱：检查引流笔记主题与直播前段排品是否一致。
- 付费流量进入后停留与转化骤降：先判断人群和承接，再决定是否继续加预算。

## 时间轴与成交节奏

结合大屏两组曲线：观看人数+支付金额、观看人数+新增粉丝数。

分析：

- 上人后是否在 10-15 分钟内出现点击、加购和订单响应；
- 在线稳定但支付曲线长期平直；
- 成交是否只靠少数尖峰；
- 换品、换主播、福利、抽奖、违规标记前后的变化；
- 支付波峰后流量是继续扩散还是快速回落；
- 涨粉发生在什么内容、商品或互动段落。

曲线相关不等于因果。关键时间点必须尽可能用回放或运营记录验证。

经验参考：冷启动希望每 3-5 分钟出现订单信号，稳定期每 1-2 分钟可见成交浮窗；若长期 10-15 分钟才一单，通常需要重做成交节点。不要机械套用到高客单、低库存或特殊类目。

## GPM

GPM 是效率温度计，不是统一评分线。

- 优先与账号过去 7/30 天、相近时段和同主播场次比较。
- “GPM 约为客单价 8-14 倍”只能作粗略感知。
- GPM 低可由人群、价格、货盘、支付率或客单价导致，必须拆解。

## 多场比较

控制或明确以下变量：主播、时段、时长、类目、价格带、投流、活动日、货盘、新老客与私域占比。

至少报告均值、中位数和代表性场次。样本少时不做强因果结论。
