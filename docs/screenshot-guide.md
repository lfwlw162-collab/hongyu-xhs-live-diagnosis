# 截图与取数说明

## 推荐路径

1. 进入小红书千帆；
2. 左侧菜单进入“数据”；
3. 进入“直播场次”；
4. 选择合适时间范围，找到目标直播场次；
5. 点击“数据详情”；
6. 从页面顶部到底部连续截图；
7. 点击“查看数据大屏”，补充两张综合趋势截图。

## 数据详情怎么截

请保留页面标题、账号、直播起止时间、直播时长、字段名、数值和单位。不要只裁剪单个数字。

从上到下覆盖：

- 场次信息与核心数据概览；
- 核心指标；
- 全部流量渠道；
- 成交转化漏斗与互动漏斗；
- 趋势分析；
- 引流笔记明细；
- 页面继续向下出现的其他数据模块。

一张截图放不下时可分段截图，相邻截图保留重叠区域。长表格第一张应包含表头，必要时继续翻页或上传下载表。

## 数据大屏怎么截

综合趋势一次通常只能清晰对照两条曲线，请分别截图：

1. 观看人数 + 支付金额；
2. 观看人数 + 新增粉丝数。

两张截图都应保留：

- 顶部支付金额；
- 观看人数、互动人数、人均停留时长；
- 支付人数、支付订单数、退款金额；
- 新增粉丝人数、预约直播人数、预约进房人数；
- 被选中的曲线图例；
- 完整时间轴；
- 页面显示的讲解、营销、抽奖或违规等时间标记。

## 上传前建议遮盖

- 手机号、收货地址、订单号；
- 买家昵称、用户头像等身份信息；
- 与诊断无关的客户或员工个人信息。

不要遮盖指标名称、数值单位、直播时间、曲线图例和时间轴，否则可能导致口径误读。

不要上传密码、验证码、Cookie、密钥或登录令牌。
