## 一句话结论

本场的主要断点不在曝光，而在陌生流量进房后的前段承接：封面点击尚可，但上下滑渠道停留短、商品点击弱。下一场应优先重做首屏画面、前三十秒定位和首屏商品，而不是直接增加投流。

## 三个最重要问题

### 1. 陌生流量停留不足

- 数据事实：上下滑渠道人均停留 7 秒，低于主页和关注渠道；
- 高可信诊断：直播间对熟悉账号的人有一定承接，但陌生人很难在第一眼理解“卖什么、适合谁、为什么现在看”；
- 其他解释：该渠道人群可能与本场货盘不匹配；
- 缺失证据：开场与掉量节点回放。

### 2. 商品曝光到点击明显偏弱

- 数据事实：商品曝光人数 260，点击人数 21；
- 待验证假设：首屏商品的视觉展示、价格带或使用场景表达不足；
- 其他解释：商品卡/SKU 信息复杂，或进房人群本身偏泛；
- 缺失证据：分商品点击与讲解时段。

### 3. 支付样本不足，不能先归因于优惠

- 数据事实：支付人数只有 4；
- 诊断判断：目前更大的断点发生在点击之前，直接降价可能无法解决根因；
- 缺失证据：加购未支付原因、优惠规则与售后问答。

## 限流判断

暂不支持直接认定限流。曝光仍有规模，且停留和商品点击存在更直接的经营解释。若后台出现违规提示，或账号、商品、商城多场域同时异常下降，再进入专项排查。
