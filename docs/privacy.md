# 隐私说明

## 本仓库不收集什么

本仓库只包含 Skill 指令和参考知识，不包含独立服务器、账号登录脚本、遥测、广告追踪或主动上传数据的代码。仓库维护者不会通过本 Skill 自动获得你的截图、表格、对话或经营数据。

## 对话中的数据由谁处理

用户主动上传到 AI 对话中的截图、表格和文字，由用户选择的 AI 产品及其服务提供方按照对应的隐私政策、账号设置和工作区政策处理。这一处理不由本开源仓库控制。

## 最小化提交原则

为完成直播诊断，通常只需要经营指标、趋势曲线、渠道数据、商品数据和必要的时间信息。上传前建议遮盖不影响判断的个人信息，例如手机号、收货地址、订单号、用户昵称和头像。

无论何种情况，都不要提交：

- 密码或验证码；
- Cookie、Session、访问令牌或 API 密钥；
- 身份证件、银行卡等高敏感信息；
- 与直播诊断无关的客户或员工个人数据。

## 后台访问边界

本 Skill 默认要求用户自行上传截图或导出表格，不主动登录小红书千帆。只有用户明确要求 AI 操作其已经登录的页面，且所用客户端具备相应能力时，才可在用户授权范围内读取页面。

## 公开提问注意事项

如果你准备把诊断问题、截图或报告发布到 GitHub Issue、社群或其他公开渠道，请先做二次脱敏。公开仓库中的内容可能被搜索引擎、代码索引和第三方归档收录。
