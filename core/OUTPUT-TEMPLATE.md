# 标准复盘输出模板

根据资料完整度缩放，不为凑结构输出空章节。

## 一句话结论

指出最大问题位于哪个环节，以及最优先要改什么。

## 资料完整度与口径

- 已获得：截图、表格、回放和时间范围；
- 缺失：只列影响结论的关键项；
- 口径提醒：人数/次数、自然/付费、转化率分母、退款归属。

## 三个最重要问题

每个问题写：

1. 现象；
2. 数据证据；
3. 原因判断；
4. 其他可能解释；
5. 证据等级。

## 渠道、时间轴与货盘

- 哪些渠道贡献量，哪些渠道贡献成交；
- 公域与私域是否失衡；
- 观看、支付和涨粉曲线的波峰与空档；
- 高点击低支付、高成交高退款或零成交SKU；
- 需要回放验证的具体时间点。

## 限流判断

仅在相关时输出：确认触发 / 高度疑似 / 不能排除 / 暂不支持限流。
