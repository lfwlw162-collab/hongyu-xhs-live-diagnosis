# 用户数据清单

把这份清单发给需要诊断直播的用户。不要要求用户为了符合模板重新录入平台已经导出的数据。

## 单场快速诊断

### 1. 数据详情全部截图

路径：

`小红书千帆 → 数据 → 直播场次 → 选择时间 → 找到目标场次 → 数据详情`

从页面顶部到底部连续截图，覆盖：

- 场次信息与核心数据概览；
- 曝光、观看、平均在线、人均观看时长；
- 互动、关注、商品曝光、点击、加购；
- 支付人数、订单数、成交金额、退款；
- 全部流量渠道；
- 成交与互动漏斗；
- 趋势分析、引流笔记和页面下方其他模块。

相邻截图保留少量重叠，保留表头、字段名、数值和单位。

### 2. 两张数据大屏截图

进入“查看数据大屏”，分别选择：

1. 观看人数 + 支付金额；
2. 观看人数 + 新增粉丝数。

两张都保留顶部核心指标、曲线图例、完整时间轴和页面显示的讲解/营销/抽奖/违规标记。

### 3. 基础背景

- 类目和主要商品；
- 价格带；
- 主播；
- 是否投流；
- 本场目标；
- 是否出现违规提示或异常掉量。

## 深度复盘补充资料

- 商品/SKU明细；
- 退款及退款原因，最好能回溯原成交场次；
- 推广消耗、进房与成交数据；
- 成交波峰、掉量、换品、换主播等关键时间点回放；
- 封面、标题、首屏画面、排品顺序与福利节点；
- 至少一场表现好和一场表现差的可比场次。

## 上传前脱敏

建议遮盖手机号、地址、订单号、买家昵称、头像及无关员工信息。

不要上传密码、验证码、Cookie、Session、访问令牌、API密钥、身份证件或银行卡信息。

不要遮盖指标名称、单位、直播时间、曲线图例和时间轴。
